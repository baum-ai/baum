# Custom tile kit

The runtime a custom tile is written against, inlined into every tile's frame
document. See "Custom tile kit" in [ARCHITECTURE.md](../../ARCHITECTURE.md).

- `v1/`: kit major 1. Frozen and additive only: never remove, rename or change
  the meaning of anything `v1/manifest.json` lists. Add names instead.
- `tokens.css`, `fonts.css`: generated by `app/scripts/build-tile-kit.mjs`
  (`pnpm tile-kit` in `app/`); do not edit.
- `kit.go`: `Compose`, `CSP`, `Supported`, the manifest. `lint.go`: `Lint`.

Go tests: `go test ./tiles/kit/`. Runtime tests: `app/src/tile-kit/`.
Pictures: `just local_app::tile-kit-screens`.
