Submit the review by calling the `StructuredOutput` tool once, with the
complete document as its input, after you have finished reading and run the
final checklist. Do not call it with a draft or a partial document, and do
not write the document in a message: text outside the tool call is
discarded. If the tool itself rejects the input as not matching its schema,
correct the document and call it again; that is the only reason to call it
more than once.
